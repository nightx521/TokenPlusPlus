# 平台支持

当前范围是 Windows 本地多平台余额与额度聚合。下表是已实现的四个平台；新增平台以可验证的查询来源为准。

| 平台 | 显示内容 | 数据来源 | 前提与限制 |
| --- | --- | --- | --- |
| DeepSeek | 总余额、充值余额、赠金，按币种分别显示 | 官方余额 API | 官方 API Key；没有返回的到期日保持未知 |
| 华为云 | 有效、未冻结、可用代金券的剩余额度与到期日 | 官方账务 API | 中国站默认，可切国际站；需要账务查询 AK/SK，国际站仍需实际账号验证 |
| Codex | 实际额度窗口、剩余百分比、重置时间 | 本机官方 App Server | 安装官方客户端/CLI 并登录；聊天窗口无需运行，查询会短时启动子进程 |
| Antigravity | 额度池的短期与每周余量、重置时间 | 第三方 Antigravity Tools 管理 API | 本机或云端 Tools 服务需运行，官方 IDE 无需运行；已在 Tools 4.9.6 实测，其他版本可能需适配 |

华为云统计账号内全部可用代金券，**没有筛选 MaaS 适用范围**，不能将合计理解为保证可用于模型调用的额度。各券实际抵扣资格以平台规则为准。不同币种不相加。

Antigravity 多个模型可能共享额度池，不能累计成额外额度。五小时与每周分别显示，重置时间与百分比保持对应。并非所有账号都会返回相同窗口；缺失值保持未知。

## 刷新与费用

默认余额每 10 分钟、Codex 每 3 分钟、Tools 每 5 分钟查询，可分别调整。查询失败保留上次成功值，标为过期并提供单平台重试；服务限流时按等待时间退避。时间按北京时间显示。

本应用不发送推理请求。余额与代金券查询不会消耗模型 Token 或抵扣模型代金券；接口仍可能有权限、限流及平台侧规则。Codex 查询子进程有短时 CPU 和内存开销，轻量使用可把间隔设为 5–10 分钟。

## 新平台提案

请说明服务名称、希望展示的指标、是否有官方查询文档及鉴权方式。OpenAI 兼容的聊天接口只代表推理协议相似，**不代表余额和订阅额度接口通用**；需要逐平台实现账务适配。

## Tools 服务地址与综合视图

服务地址支持本机回环 HTTP 和云端 HTTPS（保留系统证书校验），可包含反向代理前缀。组件自动衔接 `/api/accounts` 和账号额度查询路径，不通过 `/v1` 调用模型。管理密钥绑定到规范化服务地址；更换地址需重新填写，原本机端口配置自动兼容。界面保存连接后读取实际账号列表，连接失败会显示原因并保留旧数据。

桌面标题下拉框提供单账号与综合平均。当前综合采用等权，不基于套餐价格猜容量倍数；异套餐混合只应理解为平均百分比。耗尽账号的已知 0% 参与；停用/受限账号不参与。失败与缺失保持未知并标记不完整，不能将部分数据冒充完整总额度。不同账号、模型池和时间窗口不混加；共享池在每个账号内去重。综合没有统一重置时间，单账号仍显示真实时间。

查询最多 64 个参与账号，并发上限 4、总查询时限 60 秒。没有实际云端账号时，本机回环协议测试不能替代用户云部署的真实兼容验证。

0.6.0 为 Tools 凭据增加目的地址绑定，仍保存在 Windows 安全存储。升级后如改用 0.5.x 旧程序，旧程序不能识别新凭据格式；如需回退应在旧版重新保存该平台密钥。其他平台凭据格式不变。

## 全局显示项与刷新结果

“显示项”统一选择 Gemini Models、Claude & GPT Models 或两者，不依赖当前账号是否载入；切换账号或综合平均会保留选择。每个账号先按显示项过滤再参与综合，兼容标准池名称与常见别名。来源不提供对应数据时保持未知，不将其他模型额度充当所选额度。

修改选项静默保存。新查询完成前保留原指标、原更新时间和实际来源视图，显示“更新中 · 旧值”或“上次结果”；成功后整体替换，失败继续保留带标记的旧数据。新目标是综合视图时，旧单账号结果的重置时间不会被误标为综合重置。手动移除凭据仍清除该平台缓存。
