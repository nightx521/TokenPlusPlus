# 新增平台适配器

先确认可查询什么，再实现展示。仅支持 OpenAI 兼容推理协议不足以接入余额。

## 当前结构

`src-tauri/src/adapters.rs` 是封闭的平台注册入口，负责平台 ID、凭据需求、查询分发、刷新间隔和固定控制台网址。现有解析位于 `providers.rs` 与 `antigravity.rs`。统一结果是 `model.rs` 的 `Snapshot` / `Metric` / `Detail`，缓存、退避、独立刷新位于 `lib.rs`。

没有动态加载可执行插件或任意 URL 请求功能。扩展需修改源码并发布新版本，便于审查请求地址与凭据边界。

## 实现步骤

1. 记录官方文档、查询接口、认证权限和数据时效。非公开/第三方方式需明确来源、兼容版本、是否读取登录信息，以及实际请求边界。
2. 新增 Rust 查询和独立解析函数。金额使用 `rust_decimal`，分页完整才返回成功；同币种求和，额度池按稳定 ID 去重。
3. 为 `Adapter` 增加枚举分支和 `ALL` 注册，明确凭据需求、查询超时、刷新间隔与固定平台地址。未知 ID 必须拒绝，不能回退成别的平台。
4. 在 `Store::default()` 加入初始快照；在 `src/types.ts` 更新 `ProviderId`、平台名称、本地图标及演示数据。前后端平台 ID 保持一致。
5. 在设置界面实现对应凭据录入/移除和连接配置校验。使用 `TokenPlusPlus` 系统凭据服务，前端保存成功后清空输入，不返回密钥。新增设置字段使用兼容默认值；不兼容结构需迁移。
6. 补齐脱敏失败提示、配置变更后的缓存失效、单平台重试及文档。更新支持表和第三方图标许可。
7. 运行贡献指南中的检查，并在真实账号上核对一次指标与平台控制台。测试结果说明实测范围，不提交真实响应。

## 结果约定

- `Snapshot.provider` 等于注册 ID；成功有实际 `updated_at`，失败保留原成功时间。
- 金额 `value` 使用十进制字符串、`unit` 使用实际币种；百分比另填 `remaining_percent`。
- `resets_at` 是秒级 Unix 时间；缺失时 `None`。不得把相对窗口固定拼成精确重置时刻。
- 原始字段未提供时保持未知，不返回零、100% 或占位成功。
- `Detail` 只放可公开给本机界面的结果，不放请求头、令牌、密钥、完整原始响应。
- 敏感请求不得跟随重定向到其他主机；本机接口不得通过系统代理发送管理凭据。

## 需要的验证

测试正常结果、缺失字段、无权限、过期/冻结记录、重复/共享池、多币种、分页中途失败、已用转剩余的方向、秒/毫秒与重置边界。网络失败后应保留旧值并可独立恢复，不能阻塞其他平台。
